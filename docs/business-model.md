# Kineq - Business Model and Plans

## Licensing Logic

Kineq plans scale based on:
- Number of active professionals
- Number of administrative users
- Number of locations
- Advanced features
- WhatsApp usage
- Support level
- Integrations
- Onboarding needs

The main pricing driver should be the number of active professionals, not every system user.

## Plans

### Kineq Esencial

For independent kinesiologists.

Includes:
- 1 professional
- 1 administrative user
- Appointment calendar
- Patient records
- Basic clinical history
- Session evolution notes
- Online booking link
- Basic reminders

### Kineq Consultorio

For small practices.

Includes:
- Up to 3 professionals
- 2 administrative users
- Multiple calendars
- Complete clinical history
- WhatsApp reminders
- Appointment confirmation
- Waiting list
- File attachments
- Basic reports

### Kineq Centro

For medium-sized centers.

Includes:
- Up to 10 professionals
- Multiple administrative users
- Roles and permissions
- Multiple locations
- Advanced reports
- Metrics by professional
- Treatment protocols
- Digital consent forms
- Advanced follow-up
- Data export
- Priority support

### Kineq Institucional

For sanatoriums, clinics, and large institutions.

Includes:
- Custom number of professionals
- Multi-location support
- Advanced integrations
- Audit logs
- Advanced security
- SLA
- Team training
- Custom implementation
- Management dashboards
- Dedicated support
